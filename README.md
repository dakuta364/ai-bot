# AI-Ассистент для Студии Красоты (Telegram Bot)

Интеллектуальный Telegram-бот для автоматизации записи клиентов и консультирования по услугам студии красоты. Бот использует искусственный интеллект для понимания свободного текста и интегрируется с Google Sheets для ведения CRM.

## ✨ Основные функции

- **🧠 Интеллектуальный диалог:** Понимает запросы на естественном языке (благодаря Llama 3 через Groq API). Помогает выбрать услугу, уточнить цену или найти адрес.
- **📅 Автоматизированная запись:** Собирает данные (имя, телефон, дата, услуга) и создает заявки в Google Таблицах.
- **👩‍🎨 Выбор мастера:** Автоматически предлагает подходящих специалистов в зависимости от выбранной услуги.
- **❌ Управление записями:** Позволяет клиентам отменять существующие записи через бота.
- **📊 Уведомления:** Мгновенно уведомляет администратора студии в Telegram о новых заявках или отменах.
- **🔒 Безопасность:** Реализована система согласия на обработку персональных данных (ФЗ-152).
- **🕰 Сессии:** Автоматический сброс истории диалога при длительном бездействии.

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Библиотека бота:** `pyTelegramBotAPI` (telebot)
- **Искусственный интеллект:** `Groq API` (модель Llama 3.3 70b)
- **База данных/CRM:** `Google Sheets API`
- **Логирование:** `Logging` с ежедневной ротацией файлов.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш-аккаунт/dental_bot.git
cd dental_bot
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate     # Для Windows

pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории и заполните его:
```env
BOT_TOKEN=ваш_токен_телеграм_бота
GROQ_API_KEY=ваш_ключ_groq
ADMIN_ID=ваш_телеграм_id_для_уведомлений
SPREADSHEET_NAME=Название_вашей_таблицы_в_Google
TIMEZONE=Europe/Moscow
```

### 4. Настройка Google Sheets
1. Создайте сервисный аккаунт в [Google Cloud Console](https://console.cloud.google.com/).
2. Включите **Google Sheets API** и **Google Drive API**.
3. Скачайте JSON-файл ключа и сохраните его в корне проекта под именем `service_key.json`.
4. Создайте Google Таблицу и предоставьте доступ на редактирование email-адресу вашего сервисного аккаунта.

### 5. Запуск бота
```bash
python main.py
```

## 📁 Структура проекта

- `main.py` — Точка входа, логика обработки сообщений и команд.
- `ai_client.py` — Интеграция с Groq API, формирование промпта и парсинг ответов.
- `sheets_client.py` — Логика взаимодействия с Google Sheets.
- `state_manager.py` — Управление состояниями пользователей, историей диалогов и согласиями.
- `config.py` — Централизованные настройки, тексты сообщений и список мастеров.
- `utils.py` — Вспомогательные функции.
- `requirements.txt` — Список необходимых библиотек.
